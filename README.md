# MATLAB Power Systems & Matpower Practice

Welcome to my MATLAB repository dedicated to power system calculations and simulation exercises.

---

## 📌 Features & Structure

This repository is organized into distinct modules for practice and simulation:

*   **exercises/**: Fundamental MATLAB scripts, structural exercises (structs, matrices, arrays), and numerical methods.
---

## 🛠️ Environment & Setup

This repository is developed using Visual Studio Code with the **MATLAB Extension**, connected to the MATLAB runtime engine.
NOTE: You can simply use the MATLAB application alone.

### Prerequisites
* MATLAB (R2023b or later recommended)
* VS Code with the **MATLAB Extension**

### How to Run
1. Open the repository root folder in VS Code.
2. Open any .m file from the directory.
3. Select any code block or line and press **F9** to execute in the integrated MATLAB terminal.
4. Alternatively, use %% cell sections and press **Ctrl + Enter** to run individual sections.
